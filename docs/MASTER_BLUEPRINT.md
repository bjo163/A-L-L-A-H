## Operational journey model
Journey = actual experience; Path = reusable potential plan; Road Network = graph of multiple paths;
Timeline = dated/ordered events; Milestone = reviewed progress; Mandate = expiring, revocable authorization.
Path lifecycle: DRAFT → RESEARCHING → REVIEW → PILOT → ACTIVE → MAINTAIN/REVISE → RETIRE; high-risk cases may SUSPEND any active path. Transitions require immutable history, authorized operator, reasons, and safety checks.
Governed ACTIVE path gate = authenticated responsible owner + authorized maintainer + evidence review + consent + completed risk review.
A self-directed personal journey does NOT require 100CENTER permission to exist.

## Local AI model
- A pool of few reusable tools/agents (research, retrieval, evidence check, path planner, safety review assistant, report drafting), not 99 supernatural AI agents.
- Retrieval always emits source identity and passage reference. Proposed changes do not execute themselves.
- No AI authorization to declare revelation, prophecy, ultimate salvation, divine ranking, hidden knowledge or spiritual identity.
- Risky real-world actions must be confirmed by an authorized human and carry rollback/revocation.
- AI output is a suggestion, not an authoritative divine message.

## Minimal acceptance test (G03)
Create a consented sample community journey → design path → attach 4-source corpus evidence without conflation → assign Pathfinder, WING and Renewal Steward → verify evidence → assess risk → human approve → activate → change state → suspend/retire → replay event log. Verify tenant isolation and denied unauthorized writes.
