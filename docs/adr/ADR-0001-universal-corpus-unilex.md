# ADR-0001 PROPOSAL — UNIVERSAL LEXICON & FOUR-SOURCE RESEARCH
**Status:** PROPOSED — LOCAL TO EMPIRE OF THE LIGHT; **NOT APPROVED IN GEN2**.

## Context
Project concept docs had distinct names for shared concepts, and source-specific comparisons risked losing edition identities. The user requested one universal terminology layer and support for Taurat, Zabur, Injil and Qur'an research.

## Decision proposed
- Maintain UNILEX as a versioned source-aware registry with IDs and review states.
- Initial text-source families: Torah, Psalms, canonical Gospels, Qur'an.
- Keep theological scripture *referents* separate from extant textual *witnesses*.
- General research queries perform source-preserving retrieval, never automatic forced cross-faith harmonization or divine truth ranking.
- Existing bounded \`moonwitness-prophetic\` source priority is **not** generalized.
- Preserve Gen2's single HTTPS/OpenAPI public API; assign one owner before importing into Gen2.

## Consequences
Benefits: fewer ambiguous agents, stable citations, inspectable editorial changes.
Costs: licensing/edition review, multilingual analysis, provenance management.
Risks: doctrinal misinterpretation, PII leakage, retrieval errors. Mitigate with attributions, human review, explicit epistemic lanes and negative tests.

## Open approvals
Corpus capability owner; Journey/Path domain owner; licensed source editions; API contract owner; data retention officer; migrations and backout plan.
**No downstream Gen2 code changes authorized by this local proposal alone.**
