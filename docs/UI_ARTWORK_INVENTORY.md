## Findings for the next art-direction gate

1. The specified motif set is present in package-owned source; source search found no Portal or Command Center `.css` file. The two apps import package stylesheet entries, with MapLibre styling isolated in its package adapter.
2. Some families are intentionally shared and composable (`MangaOrbit`, `MangaSfx`, speed lines); the Portal hero remains a unique composition assembled in the package. Package ownership is achieved for these sources, but visual convergence is not yet proven.
3. The Portal art has overlapping treatment layers: base dark styling, light-theme overrides, and a manga profile for the same core, satellite, rays and accent elements. This is a known cascade/design review area tracked by UI-C06-04; it is not equivalent to duplicated app ownership.
4. There is no decision in this inventory that the Orbit logo and orbit illustration are the same identity asset. Brand marks remain governed by C02 and motif usage by C04.
5. Named geometric hero decoration is hidden or nested under the hero's named image; SFX and the optional empty/error state SVGs are explicitly hidden. C04-06 source separation is complete; rendered accessibility acceptance remains a C14/C16 review gate.
6. C04-02 removed two redundant catalog-only overlays (duplicate screentone and duplicate ray field) and an ineffective Portal hero `speedLines` prop whose background image was overwritten by the product background shorthand. Portal rays remain product-specific; telemetry/loading rays remain shared. This is a source-level ownership/cascade finding and still needs rendered comparison in the full visual matrix.
7. C04-09 removed perpetual ring glow and an ineffective `MangaEffect.spin` pseudo-element animation. Remaining infinite animation is attached to active loading/progress or live map/Sentinel state; viewport pausing and actual offscreen behavior still need runtime review.
8. Reduced-motion CSS removes reveal/SFX/loading ornament, skeleton shimmer/spin, and hover movement; Portal hero copy/diagram labels, state titles/actions, and loading text remain in the DOM. Map markers also suppress decorative pulse/entrance explicitly. Preference simulation remains a browser acceptance gate even though the static fallback is present in source.
