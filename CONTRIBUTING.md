# Contributing
Use `dev` → pull request to `main` → review → merge commit. Only these two branches are used for now. See [automation and versioning](docs/AUTOMATION.md).
Propose new concepts with stable ID, English/Indonesian labels, narrow definition, sources, sensitivity/context, relations and reviewer. Never reuse deleted IDs.
Do not paste copyrighted book translations without licensing evidence; quote no long source passages.
If changing an existing sense, document whether it is compatible; use an explicit migration when changing its meaning.
Discussions of different traditions must attribute theological claims; never silently fuse a claim into an empirical fact.
For Gen2-changing integration, use the formal Gen2 architecture decision process before implementation.
Run \`npm run validate\` locally before review.
